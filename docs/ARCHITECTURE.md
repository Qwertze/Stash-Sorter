# Architecture

The plugin runs inside one AquariusProxy JVM. The loader reads `zenithproxy.plugin.json`, generated by the API JAR's annotation processor from `@Plugin`. `QwerteStashPlugin.onLoad` registers the config, tracker, sorter, automatic drop module, ground pickup module, manager and local command tree.

| Subsystem | Responsibilities and data flow |
|---|---|
| Tracking and storage | `StashTracker` observes containers and server/session changes. `Stashes` selects a stash by server and configured name. `Stash` serializes boxes, held items and recoverable in-flight work. `StashIndex` renders a readable snapshot on one worker. |
| Sorting and game actions | `StashSorter` sequences pathfinding, window clicks, crafting, shulker recovery and delivery on ticks. `ContainerPacing`, `SurveyRetry` and recovery helpers model time and eligibility. `AutoDrop` and `GroundItems` also interact with inventories. |
| Orders | `OrderDriver` turns claim, heartbeat and status replies into actions. `OrderFlow` coordinates the host through its interface. `StockPlanner`, `CraftPlanner` and the packing types produce plans. `OrderSim` supplies a controlled world for tests. |
| Manager connection | `StashManager` moves work between ticks and background workers. `ManagerIndex` builds report data. `ManagerHttp` signs requests and validates replies. `DashboardLink` polls, publishes state and serializes changes. `ViewerFeed` sends updates while watched. |
| Operator settings | `StashCommand` exposes local actions. `SettingsSpec` describes editable settings, `ConfigSchema` exports allowed values and `ConfigApplier` validates a change against policy and optional expected value. |

## Sorter inventory and exploration

`CarrySlots` translates configured ranges into inventory indexes and reads only eligible slots through a caller-supplied item lookup. The sorter can reclaim a stack after reconnect when its item ID matches the saved ID for that slot. The manager's free-capacity check counts only empty slots.

`PerimeterColumns` computes the chunks touched by the area and selects the nearest eligible waypoint. Ties use the original column scan order. `WaypointProgress` tracks one waypoint's elapsed active ticks, arrival and progress. It asks a two-method pathing interface about ownership and availability. `Activity` implements that interface against Baritone. `StashSorter` issues movement requests, restores pathfinder settings, reads loaded containers and reports results on the game tick.

## Concurrency and data lifetime

The proxy owns the event loop, account and game connection. Network replies destined for the game are dispatched on tick. The dashboard's independent poller puts signed jobs in a 32-entry blocking queue. One worker handles accepted jobs in order. A full queue pauses the poller. Stopping clears pending jobs and interrupts waiting threads. An in-progress settings job that disables its own link can finish its result.

Stash saves for one object serialize. A unique temporary file in the same directory is written completely before replacement. Index rendering runs outside the scheduling lock. The writer checks the current per-file state before publishing, so a pending snapshot from a forgotten stash cannot recreate its index. Same-directory rename is atomic when the provider supports it. The fallback performs a replacement move. These operations make no disk-flush guarantee after sudden power loss.

Persisted stash filenames and JSON fields remain compatible with the input project. Missing legacy collections are normalized on read. Missing identity fields can be supplied from the selected stash. A conflicting stored identity blocks loading. Broken data needs a successful recovery copy before an empty stash can replace it. Backups retain their separate corruption and prune prefixes.

## External contracts

AquariusProxy supplies the signed-in session and Minecraft 1.21.4 protocol implementation. The separately deployed Stash Manager owns dashboard authentication, endpoint behavior and server-side order storage. The API key is used for signing. TLS protects remote traffic in transit. The bundled recipe resource is version-specific. There is no independent database or HTTP listener in the plugin.
